# Agents & platforms — artwork references

20 source-based brand marks in SuperIntelligence’s original isometric presentation, each exported in five styles. The exported illustrations are unofficial; their source geometry comes from the official assets or identified vector libraries below.

The [MIT license](LICENSE) covers SuperIntelligence’s original system icons, code, and presentation. Third-party marks retain their owners’ rights and source terms; this package does not relicense them or grant trademark rights. Source-license notices and downloaded reference assets are included in [vendor/brand-logos](vendor/brand-logos/). Use the linked official resources when you need unmodified brand assets.

Identity references checked on 2026-10-20. Color preserves source flat colors where available. Gradients are simplified to flat colors to keep the exports free of raster images, filters, and gradients. The other four styles use monochrome or tonal versions while retaining the logo geometry.

## Adaptations and source terms

- **Hermes Agent:** Original portrait paths from the official Hermes master icon; app tile and clipping wrapper removed, full portrait bounds fitted to the face. Source terms: MIT — Nous Research source; brand rights retained by Nous Research.
- **Grok Bot:** Native compound logo path from Lobe Icons, checked against the official brand reference. Source terms: MIT — LobeHub vector source; brand rights retained by the respective owner.
- **Meta Muse:** Original Muse squiggle path; blue gradient replaced with solid #0064E0 for the flat-vector set. Source terms: Meta brand asset; trademark and artwork rights retained by Meta.
- **Claude:** Native compound logo path from Lobe Icons, checked against the official brand reference. Source terms: MIT — LobeHub vector source; brand rights retained by the respective owner.
- **OpenAI:** Native compound logo path from Lobe Icons, checked against the official brand reference. Source terms: MIT — LobeHub vector source; brand rights retained by the respective owner.
- **Gemini:** Exact vector silhouette extracted from the official asset. Its raster/gradient interior is replaced by the source base blue #3186FF to retain flat, vector-only output. Source terms: Brand-owned asset; see the linked official brand reference for usage terms. Trademark rights remain with the respective owner.
- **Perplexity:** Native paths, mitered strokes, and True Turquoise color from the official brand kit. Source terms: Brand-owned asset; see the linked official brand reference for usage terms. Trademark rights remain with the respective owner.
- **Mistral:** Official 2026 pixel geometry and five solid color bands. Rectangles are converted losslessly to paths; artwork-only viewBox removes export padding. Source terms: Brand-owned asset; see the linked official brand reference for usage terms. Trademark rights remain with the respective owner.
- **GitHub Copilot:** Official Primer product UI mascot icon. GitHub no longer uses this mascot as the standalone marketing logo; product UI iconography retains it. Source terms: MIT (Primer Octicons, copyright 2026 GitHub Inc.); GitHub trademarks remain with GitHub.
- **Cursor:** Official 2D cube with its original native compound path and cutout. Source terms: Brand-owned asset; see the linked official brand reference for usage terms. Trademark rights remain with the respective owner.
- **OpenClaw:** Exact official lobster curves and antenna strokes. Gradient body is flattened to its original red stop #FF4D4D. Circles are converted losslessly to arc paths; monochrome styles retain white eye knockouts. Source terms: Brand-owned asset; see the linked official brand reference for usage terms. Trademark rights remain with the respective owner.
- **Manus:** Unmodified official hand glyph compound path, including original fill rule and interior details. Source terms: Brand-owned asset; see the linked official brand reference for usage terms. Trademark rights remain with the respective owner.
- **DeepSeek:** Whale path extracted from the official header; text lockup omitted. Source terms: Official website asset; brand rights remain with DeepSeek.
- **Qwen:** Current official blue mark vector traced from transparent favicon; three original shapes retained. Source terms: Official website asset; brand rights remain with Alibaba Cloud.
- **Kimi:** Dark variant for a light carrier; K and blue apostrophe geometry preserved. Source terms: MIT — Copyright (c) 2023 LobeHub; brand rights remain with Moonshot AI.
- **Z.ai / GLM:** White Z paths from app icon rendered dark on the shared light carrier. Source terms: Official website asset; brand rights remain with Z.ai / Zhipu.
- **MiniMax:** Exact waveform geometry; gradient replaced with a single coral brand tone. Source terms: MIT — Copyright (c) 2023 LobeHub; brand rights remain with MiniMax.
- **Doubao:** Vector trace of official assistant portrait; flat color regions replace raster shading. Grayscale regions preserve facial features in monochrome variants. Source terms: Official website asset; brand rights remain with ByteDance.
- **ERNIE:** Exact ERNIE / Wenxin cube paths; gradient replaced with blue spot color. Source terms: MIT — Copyright (c) 2023 LobeHub; brand rights remain with Baidu.
- **Tencent Hunyuan:** Official circular mark with mask flattened. Monochrome variant uses corresponding LobeHub mark to preserve internal cutouts. Source terms: Official color asset (Tencent); monochrome geometry MIT — Copyright (c) 2023 LobeHub. Brand rights remain with Tencent.

Hermes uses the detailed portrait paths from Nous Research’s master SVG. Qwen and Doubao are vector traces of the current official reference images; the exported SVGs contain paths, not embedded bitmaps.

Vector data lives in [src/logos](src/logos/), with product definitions in [featured brands](src/icons-brands-featured.mjs), [global brands](src/icons-brands-global.mjs), and [Chinese platforms](src/icons-brands-china.mjs). The shared [tile carrier](src/brand-kit.mjs) controls the presentation. Source URLs, notes, terms, and search aliases are also stored in [manifest.json](manifest.json).
